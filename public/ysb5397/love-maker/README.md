# love-maker

12가지 조건을 무작위로 조합하는 애인 만들기 필터 게임. 별도 라이브러리나 서버 API 없이 동작하는 정적 웹 앱이다.

## 실행

저장소 루트에서 `npm run dev`를 실행한 뒤 `http://127.0.0.1:4192/ysb5397/love-maker/`에 접속한다. ES 모듈을 사용하므로 HTML을 파일 탐색기에서 직접 열지 말고 HTTP 서버를 이용한다.

## 기능

- 성별, 나이(20~52세), 키, 체중, 직업, 국적, 기혼 여부, MBTI, 성격, 취미, 연애 스타일, 첫 데이트 랜덤 생성
- 모두 / 남성 / 여성 선택, 세로 릴 순차 공개, 빠른 생성, 진행 중 즉시 공개
- 후보가 위에서 아래로 흐르다 멈춘 뒤 다음 항목으로 이동하는 필터 화면
- 완료 시 카드 없는 세로 프로필 목록과 1080 × 1440 PNG 이미지 다운로드
- 모바일 공유 기능 또는 클립보드 복사, 사용할 수 없으면 수동 복사 창 제공
- 공통 ToyRuntime을 통한 프로필·설정 복원
- 반응형 화면, 키보드 접근, 모션 감소 설정 지원

모든 항목은 독립적인 랜덤 값이며 실제 인물, 신체 평가 또는 궁합과 관계없는 가상의 프로필이다. 카메라와 Instagram 연동은 사용하지 않는다.

## 파일과 연동

- `index.html`: 화면 구조와 카탈로그 메타데이터
- `style.css`: 페이지 전용 스타일
- `model.mjs`: 항목 후보, 생성 및 검증
- `app.mjs`: 공개 애니메이션, 다운로드, 공유 및 상태 저장
- `heart.svg`: 아이콘

새 파일은 모두 `public/ysb5397/love-maker/` 안에 있다. 기존 `/shared/theme.css`, `/shared/runtime.js`, `/shared/runtime.css`를 불러오며 공통 파일은 수정하지 않는다. 기존 카탈로그 수집기가 제작자를 `ysb5397`, 카테고리를 `게임`으로 인식한다. 정상 빌드·배포 과정에서 프로젝트 목록이 갱신된다.
