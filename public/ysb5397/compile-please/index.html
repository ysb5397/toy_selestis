01 / 코드의 기본

코드는 위에서 아래로 실행합니다. ;는 문장의 끝이고 { }는 함께 실행할 블록입니다. // 뒤는 실행하지 않는 주석입니다. main은 프로그램을 시작하는 메서드이며 별도 안내가 없으면 제출 코드는 main 안에 있습니다.

02 / 값과 출력

=는 오른쪽 값을 왼쪽 변수에 저장합니다. ==는 두 값이 같은지 비교합니다. System.out.print(값)은 값을 줄바꿈 없이 출력합니다. 따옴표는 문자열의 경계이며 출력에 포함되지 않습니다.

System.out.print("가");
System.out.print(2);
// 출력: 가2

03 / 심사의 순서

코드 심사는 출력 또는 컴파일 가능 여부를, 개념 심사는 파일·도구·상황의 설명을 확인합니다. 자료 행이나 신청 내용을 선택하고 규정을 찾아 대조하십시오. 모순 증거를 확보하면 반려할 수 있습니다. 컴파일 오류가 있으면 프로그램은 실행되지 않습니다.

규정 이름을 몰라도 기호 색인에서 ++, &&, [] 같은 모양으로 찾을 수 있습니다. 규정을 읽는 것과 대조할 규정으로 선택하는 것은 별개의 조작입니다.
