# 코드 심사국

Papers, Please의 서류 대조 방식에서 영감을 받은 오리지널 Java 21 LTS 학습 게임. 별도 패키지나 서버 API 없이 실행한다.

언어·API·정답 판정의 기준은 **JDK 21 LTS의 정식 기능**이다. Preview 기능은 사용하지 않는다. 패턴 switch와 record 패턴은 Java 21 정식 기능이므로 고급 과정의 확장 후보에 포함한다. 현재 문제는 기존 18건이다.

- 경로: `/ysb5397/compile-please/`
- 자료형·연산 / 조건문·반복문 / 클래스·객체를 복수 선택한다.
- 주제별 6건, 전체 18건을 무작위 순서로 심사한다. 6건마다 근무일이 바뀐다.
- 코드 한 행 또는 신청 결과를 클릭하고 규정집의 조항을 골라 ‘대조하기’를 누른다. 결과는 일치 / 모순 확정 / 비교 대상 아님으로 구분한다. 코드 행은 해당 프로그램 전체 문맥을 가리키는 증거 지점이다.
- 승인은 바로 가능하며, 반려는 대조로 모순 증거를 확보해야 활성화된다. A/D 단축키와 Enter/Space 버튼 조작을 지원한다. 외형 선택 폼 조작 중에는 판정 단축키를 무시한다.
- 모순 증거는 선택 해제·규정 탭 이동·이어하기 후에도 유지된다. 문제 내용과 일치하는 증거를 다시 검증해 복원하며 다음 신청자에게는 넘기지 않는다.
- `comparison.js`는 고정 문제 18개의 규정 ID·코드 행·실제 출력을 사용한다. 임의 Java를 해석하는 범용 분석기가 아니다. `npm run test:java`는 증거의 실제 출력까지 JDK 21과 비교한다. 거부 사건·GC팀은 아직 연결하지 않았다.
- 판정 직후 해설, 근무 성적표, 오답 재심사, 브라우저 자동 저장을 지원한다.
- 임의 Java 코드를 실행하는 환경이 아니라, 검증한 고정 문제를 판정하는 학습 게임이다.
- 코드·문제는 `cases.js`, 상태와 픽셀 그래픽은 `game.js`, 화면은 `index.html`과 `style.css`에 있다.
- 폰트 CDN을 불러오지 못하면 시스템 한글 글꼴과 고정폭 글꼴로 표시한다.
- 승인·반려 PNG 인장은 서류 하단의 전용 날인란에 표시한다. 나무 도구 이미지는 두 버튼이 공유하고, 실제 HTML 이름표와 색으로 구분한다. 눌림은 CSS로 표현하며 모션 감소 설정을 따른다.
- 이미지 로딩 실패 시 텍스트 버튼·도장으로 대체한다. 선택한 도장과 정답 여부는 독립적으로 표시한다. 에셋과 생성 프롬프트는 `assets/ASSETS.md`에 정리했다.
- 도장 선택 시 도구가 날인란으로 이동하고 약 0.44초에 인장이 찍힌다. 약 0.76초 후 도구가 물러나면 해설이 나타난다. 모션 감소 설정, 이미지 미준비, Web Animations 미지원 시 결과를 즉시 표시한다. 연출 전 판정을 저장하며 도중에 주제 선택으로 나가거나 새로고침해도 이어하기에서 결과를 복원한다.
- 방문자는 `visitors.js`의 공통 96×112 픽셀 격자에서 얼굴형·피부색·머리·머리색·복장·복장색·안경·액세서리를 독립 조합한다. 생성 이미지 초안 2명은 참고 자료로 보존하고 실제 조합형 캐릭터는 Canvas 레이어로 그린다.
- 외형 작업실에서 직접 선택하거나 랜덤 조합을 고정할 수 있다. 고정 외형은 별도로 브라우저에 저장한다. 자동 모드에서는 근무 시작 시 저장하는 시드와 문제 ID로 외형을 결정하므로 판정 전후·새로고침·오답 재심사에서 동일인이 유지된다. 외형과 정답 여부는 연결하지 않는다.
- 몸통·머리 레이어에 호흡, 등장, 끄덕임만 적용하고 표정은 중립으로 고정한다. 모션 감소 설정과 탭 비활성화를 반영한다. 생성한 낮 배경을 실제 창구에 사용한다.

로컬 확인: 저장소 루트에서 `npm run dev`. 동작 검사: `node --test tests/compile-please.test.cjs`.

Java 실제 실행 검증: JDK 21의 `java`, `javac`를 PATH에서 사용할 수 있는 환경에서 `npm run test:java`. `cases.js`의 `javaRelease: 21`을 기준으로 `javac --release 21`로 컴파일한 뒤 Java 21 런타임에서 18개 문제의 실제 출력과 승인·반려 판정을 확인한다. 결과는 `outputs/compile-please-validation-21/results.json`에 기록하며 사이트 배포에는 포함하지 않는다. 브라우저에서 게임을 플레이하는 데에는 JDK 설치가 필요하지 않다.
