## 심사와 규정집

코드 심사 58개는 정상 출력 50개와 컴파일 오류 8개입니다. 개념 심사 5개는 실행 결과 대신 파일·도구·상황의 설명을 심사합니다. 자료 행 또는 신청 내용과 관련 규정을 선택하여 대조합니다. 결과는 일치·모순 확정·비교 대상 아님입니다. 관련 없는 조합은 정답을 공개하지 않습니다. 반려에는 모순 증거가 필요합니다. 이 엔진은 고정 문제은행을 사용하며 임의 Java 코드를 해석하지 않습니다.

출근 전과 근무 중에 전체 규정집 및 코드 읽는 법을 열 수 있습니다. 필요한 규정은 모두 공개하며 시간 제한은 없습니다. 복수 주제 선택, 6건마다 근무일 구분, 해설·성적표·오답 재심사·자동 저장을 지원합니다. 폼 또는 규정집 대화상자를 조작하는 동안 A/D 판정 단축키는 실행하지 않습니다.

도장·이미지 실패 시 글자 대체·모션 감소·조합형 방문자를 유지합니다. 외형 작업실과 고정 외형 조작은 제거했습니다. 방문자는 근무 시드와 신청자 ID에 따른 무작위 외형으로 등장하며 새로고침·판정 후에도 같은 인물을 유지합니다. 외형은 정답·행동과 무관합니다. 에셋 기록은 assets/ASSETS.md에 있습니다.

## 고정 심사대와 규정집

페이지 전체 스크롤 대신 브라우저 가용 높이(100dvh) 안에서 조작합니다. 왼쪽은 방문자·신청 내용·코드, 오른쪽은 규정집이며 하단에는 대조·승인·반려가 고정됩니다. 긴 코드·목차·조항·해설은 각 영역 안에서만 스크롤합니다. 좁은 화면은 서류/규정집 탭으로 전환하며 판정 후 해설 탭을 자동으로 엽니다.

규정집은 주제 목차와 한 조항을 동시에 표시합니다. 기호 색인과 키워드 검색, 직접 지정하는 책갈피, 조항 넘김을 제공합니다. 읽기와 대조 선택은 별개이며 반려에는 실제 모순 증거가 필요합니다. 판정 후 해설은 오른쪽 자리에 표시하고 규정집과 오갈 때 읽던 조항·검색어·책갈피·스크롤 위치를 유지합니다. 탐색 상태는 compile-please:handbook:v1로 근무와 별도 저장합니다.

## 파일과 저장

- cases.js: 기존 18개 문제의 원본 데이터와 ID입니다.
- curriculum.js: 11개 주제·48개 규정, 기존 문제 재분류·해설 개편, 신규 45개 서류입니다. cases.js 다음에 로드합니다.
- comparison.js: 관련 쌍과 증거를 검증합니다. fingerprint에는 문제 종류·예상 상태·관련 규정 내용도 포함합니다.
- game.js: 근무·판정·저장·연출·규정집을 관리합니다.
- visitors.js: 공통 96×112 Canvas 격자의 독립 외형 조합과 중립 표정의 몸 움직임입니다.
- curriculum.css: 교재 주제 선택의 기본 스타일입니다.
- desk.css: 브라우저 가용 높이 안에 배치하는 심사대, 고정 대조·도장, 작은 화면의 탭 전환입니다.
- handbook.js: 주제·조항 목차, 한 조항의 규칙·일반 예시·주의, 기호 색인·검색·책갈피입니다. 현재 문제를 읽지 않고 동일 조건에는 동일한 탐색 결과를 제공합니다.
- .checks/: 프로젝트 검사입니다. 숨김 폴더로 카탈로그·버전 생성에서 제외합니다.

근무 저장 키 java-inspector:v1을 유지합니다. 과거 java-inspector:look:v1의 고정 외형 설정은 더 이상 적용하지 않습니다. 기존 근무의 문제 ID와 판정을 복원할 수 있습니다. 개편 전 미확정 증거는 fingerprint가 달라 다시 대조해야 합니다. 기기나 origin이 바뀌면 localStorage는 자동 이전되지 않습니다.

## 실행과 검사

저장소 루트에서 외부 패키지 없이 정적 미리보기를 실행합니다.

```powershell
python -m http.server 4193 --bind 127.0.0.1 --directory public
```

주소: http://127.0.0.1:4193/ysb5397/compile-please/

프로젝트 전용 자동 검사는 Node 22에서 확인한 jsdom 26.1.0을 별도로 사용합니다. 저장소의 다른 앱 의존성을 변경하지 않습니다.

```powershell
npm ci --prefix public/ysb5397/compile-please/.checks
npm test --prefix public/ysb5397/compile-please/.checks
```

Java 검증은 JDK 21의 java·javac가 필요합니다. PATH가 다른 JRE를 가리키면 현재 터미널에서 JAVA_HOME을 설치된 JDK 21 경로로 지정하십시오. 시스템 설정 변경은 필요하지 않습니다.

```powershell
npm run test:java
```

정상 출력 50개는 정확한 stdout을 비교하고 컴파일 오류 8개는 실제 javac 실패를 확인합니다. 결과는 .checks/results/latest.json에 기록합니다. 개념 심사 5개는 실행 대상에서 제외하고 공식 명세로 검토합니다. 런타임 예외 심사와 무한 생성기는 아직 연결하지 않았습니다.
