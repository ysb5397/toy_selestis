## 1. 이번 기록의 우선순위

Drive의 이전 백업·진행 기록은 그대로 보존합니다. 이번 기록·TODO·ZIP·체크섬은 별도의 새 파일로 추가합니다. 과거 구현 이력은 이전 기록을 참조하며, 후속 정책은 이번 TODO.md를 우선합니다.

가장 중요한 정정은 반려 정책입니다. 사용자는 모순을 발견하지 않아도 반려할 수 있고 판정 오류에는 페널티가 있어야 한다고 결정했습니다. 모순 발견은 오로지 GC팀을 호출하기 위한 충분 조건입니다. 현재 소스의 증거 기반 반려 잠금은 아직 변경하지 않았습니다. 이번 작업은 최신 결정의 기록과 백업이며 새 게임 로직을 구현한 작업이 아닙니다.

## 2. 교재 범위와 문제은행

학교 교재 중심의 11개 범위로 개편했습니다. 자바 기본 개념 4건, 자료형 7건, 변수 6건, 연산자 9건, 조건문 3건, 반복문 7건, 배열 6건, 클래스·객체·메서드 8건, 생성자·상속 4건, final·static·다형성 5건, 패키지·접근 제어 4건입니다.

전체 63개 서류와 48개 규정입니다. 코드 심사 58개는 정상 출력 50개와 컴파일 오류 8개이며, 개념 심사 5개는 JVM·GC·파일·도구·import 설명을 다룹니다. Java 21 LTS 정식 기능을 기준으로 하며 Preview는 사용하지 않습니다. 임의 Java를 브라우저에서 실행하는 IDE나 범용 분석기는 아닙니다.

규정집을 읽고 코드를 판단할 수 있는 학습 원칙을 유지합니다. 최신 사용자는 규정의 설명이 간단해야 한다는 취지였으며 문제가 반드시 쉬워야 한다는 제한으로 해석하지 않도록 보완했습니다. 단계가 올라가면서 검사해야 하는 문법이 늘어나는 구조와 더 복합적인 문제는 TODO의 후속 설계입니다.

## 3. 화면 개편

외형 작업실과 고정 외형 조작을 제거했습니다. 방문자는 독립적인 픽셀 부위 조합으로 자동 등장하며 근무 시드와 신청자 ID에 따라 같은 인물이 유지됩니다. 과거 외형 고정 저장은 더 이상 적용하지 않습니다. 중립 표정과 몸 움직임, 모션 감소는 유지했습니다.

페이지 전체를 스크롤하는 화면을 브라우저 가용 높이 안의 고정 심사대로 바꿨습니다. 왼쪽에는 방문자·신청 내용·코드, 오른쪽에는 규정집 또는 해설, 아래에는 대조·승인·반려 도장을 배치했습니다. 긴 코드·규정·목차·해설은 해당 영역 안에서만 스크롤합니다. 작은 화면은 서류/규정집 탭으로 전환하고 판정 후에는 해설 탭을 엽니다.

규정집은 목차와 한 조항을 함께 보여 주며 규칙·일반 예시·주의로 구성했습니다. 주제 선택, 기호 색인, 키워드 검색, 조항 넘김, 책갈피를 제공합니다. 규정을 읽는 것과 대조 대상으로 선택하는 것은 별개입니다. 해설/규정집 및 서류/규정집 탭을 오가도 읽던 위치를 유지합니다. 규정집 UI는 1차 적용 상태이며 추가 검토가 필요합니다.

## 4. 현재 구현과 TODO의 구분

현재 구현은 모순 증거가 있어야 반려할 수 있습니다. 대조 결과는 일치·모순·비교 대상 아님이며, 무관한 조합은 정답을 공개하지 않습니다. 승인·반려 판정, 해설, 근무 성적표, 오답 재심사, 자동 저장과 도장 이동이 구현되어 있습니다.

새 정책인 자유 반려·판정 오류 페널티, 설정 모달, 음악·효과음 시스템, 추가 이미지, 단계별 검사 문법 확대, 반려 후 거부 행동·GC팀, 규정집 추가 개선은 이번 TODO의 미완료 작업입니다. 기존의 소리 토글·짧은 합성 톤이나 안내 모달을 완성된 음악·설정 시스템으로 설명하지 않습니다.

거부 행동과 GC팀은 아직 없습니다. 과거 회의의 최종 안내·명시적 거부 조건을 최신 GC팀 호출 정책에 자동으로 덧붙이지 않습니다. 단계 수·해금 조건·페널티 수치·호출 시점 등 세부 사항도 아직 확정하지 않았습니다.

## 7. 독립 복원

ZIP을 새 폴더에 풀고 최상위 package.json이 있는 폴더를 터미널 위치로 사용하십시오. 게임 소스는 public/ysb5397/compile-please/에 있습니다.

```powershell
node scripts/preview-standalone.cjs
```

미리보기 주소는 http://127.0.0.1:4193/ysb5397/compile-please/입니다. 미리보기 자체에는 외부 패키지가 필요하지 않습니다. 4193 포트를 이미 사용 중이면 기존 미리보기를 종료하거나 PORT 환경변수를 지정하십시오.

```powershell
npm ci
npm test
npm run check:preview
npm run test:java
```

검사 환경은 Node 22 이상과 jsdom 26.1.0입니다. Java 실제 검증에는 JDK 21이 필요합니다. PATH가 다른 JRE를 가리키면 현재 터미널에서 JAVA_HOME을 설치된 JDK 21 경로로 지정하십시오. 게임 플레이 자체에는 JDK가 필요하지 않습니다.

이번 ZIP의 최상위 package.json과 미리보기 도구는 게임만 실행하기 위한 복원 보조 파일입니다. 다른 프로젝트 소스·node_modules·.git·환경 파일은 포함하지 않습니다. 원본 package 메타데이터는 reference-original/에 보관했습니다. .checks의 불필요한 상위 저장소 로컬 링크 의존성은 복원용 사본에서만 제거하며 게임 실행 코드·테스트 본문은 그대로 복사합니다. 파일별 무결성은 SOURCE_MANIFEST.json으로 확인할 수 있습니다.
